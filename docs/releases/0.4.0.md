小花园是一款 Windows / macOS 情侣桌面宠物软件：两人各自注册，用邀请码连接，记录想法、接收伴侣提醒，一起推进共同目标。

- 单击宠物弹出快捷记录卡片；双击或右键打开主界面。
- 修复共同目标入口：可以直接“发起共同话题”，提交后在列表等待对方确认。
- 新增伴侣解绑：双方各自回到独立空间，过去的共同记录保留为各自可查看的只读历史，不分享给以后连接的伴侣。
- 删除 AI 聊天入口和模型调用，保留两个人之间的留言。
- 新增软件更新提示：服务器发布版本后提醒；由用户点击下载，通过大小与 SHA-256 校验后再打开对应安装包。

Windows x64 推荐下载 `win-x64-setup.exe` 安装，也提供 `win-x64-portable.exe` 便携版。Mac M 系列下载 `mac-arm64.dmg`，Intel 下载 `mac-x64.dmg`，打开后将“小花园桌宠”拖入“应用程序”。

两个 DMG 均在对应架构的 Mac 构建机生成，并检查磁盘镜像、应用签名、处理器架构及原生启动。Mac 目前采用 ad-hoc 签名，尚未进行 Apple Developer ID 签名或公证；Windows 安装包暂未购买代码签名证书。

`SHA256SUMS.txt` 提供安装包和源码的校验值，`verification-0.4.0.json` 记录原生构建检查与源码提交。默认通过共享服务器同步，客户端也可连接自托管的 HTTPS 服务。
