小花园桌宠 0.4.1 修复了部分网络下更新包下载缓慢的问题。调整 GitHub 安装包的下载请求，同时保持完整文件大小和 SHA-256 校验；仍由用户点击后才下载、打开安装包。

包含 0.4 的全部改动：共同话题提交、伴侣解绑与只读历史、删除 AI 聊天、服务器更新提醒。

Windows x64 提供安装版 EXE 和便携版 EXE；Mac M 系列和 Intel 分别提供 DMG。Mac 打开 DMG 后，将“小花园桌宠”拖入“应用程序”。

安装包在 Windows、Apple Silicon Mac、Intel Mac 构建机上分别生成和检查。Mac 采用 ad-hoc 签名，尚未进行 Apple Developer ID 签名或公证；Windows 安装包暂未购买代码签名证书。

`SHA256SUMS.txt` 提供校验值，`verification-0.4.1.json` 记录原生启动检查和源码提交。
