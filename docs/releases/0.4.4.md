修复可能导致系统截图后宠物消失的窗口置顶与鼠标操作中断问题，并加强透明宠物窗口的显示恢复。

- 鼠标捕获丢失、失焦或左键松开时结束拖动，取消迟到的单击与双击，避免宠物跟随鼠标误移动。
- 宠物在后台保持绘制，意外隐藏、最小化或丢失置顶状态后自动恢复；主动隐藏仍保持生效。
- Windows 下的置顶不再依赖任务栏的临时层级，最小化恢复也不会抢走其他窗口的输入焦点。
- 修正跨显示器缩放下恢复窗口时尺寸变小的问题。

Windows 本机已人工复测：使用 Win + Shift + S 截图结束后，宠物仍保持可见。
